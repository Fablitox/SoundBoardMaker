# Security Policy / Politique de sécurité

> **Soundboard Maker** — Security vulnerabilities in the Windows application, its Stream Deck integration, its official installers or its public distribution website.
>
> **Soundboard Maker** — Signalement des vulnérabilités concernant l'application Windows, son intégration Stream Deck, ses installateurs officiels ou son site public.

## 🇫🇷 Français

### Versions concernées

Les signalements sont examinés en priorité pour la **dernière version stable officiellement publiée** de Soundboard Maker. Les versions plus anciennes peuvent être examinées au cas par cas.

### Comment signaler une vulnérabilité

Si vous découvrez une faille de sécurité, **ne publiez pas ses détails dans une Issue ou une Discussion publique**.

1. Accédez à la rubrique [Security / Advisories](https://github.com/Fablitox/SoundBoardMaker/security/advisories) de ce dépôt.
2. Si le bouton **Report a vulnerability** est disponible, utilisez-le pour transmettre votre signalement **en privé**.
3. Indiquez la version concernée, les étapes de reproduction, l'impact potentiel et les informations nécessaires à l'analyse.

Si le signalement privé n'est pas encore activé, vous pouvez [ouvrir une Issue générale](https://github.com/Fablitox/SoundBoardMaker/issues/new/choose) **sans publier aucun détail exploitable**, uniquement pour demander comment transmettre le signalement de manière confidentielle.

Ne communiquez jamais publiquement de mots de passe, de jetons, de chemins contenant des informations personnelles, d'enregistrements audio privés ou de données d'autres utilisateurs.

### Périmètre et suivi

Ce dépôt public héberge uniquement la présentation, la documentation et les distributions officielles. **Le code source de l'application est privé** et n'est pas publié ici.

Les signalements de sécurité sont analysés au cas par cas. Les problèmes de fonctionnement sans impact de sécurité doivent être déclarés via les [formulaires de bugs](https://github.com/Fablitox/SoundBoardMaker/issues/new/choose).

## 🇬🇧 English

### Supported versions

Security reports are prioritized for the **latest officially published stable version** of Soundboard Maker. Older versions may be considered on a case-by-case basis.

### Reporting a vulnerability

If you discover a security vulnerability, **do not disclose its details in a public GitHub Issue or Discussion**.

1. Open this repository's [Security / Advisories](https://github.com/Fablitox/SoundBoardMaker/security/advisories) page.
2. If **Report a vulnerability** is available, use it to submit your report **privately**.
3. Include the affected version, reproduction steps, potential impact and information needed for investigation.

If private vulnerability reporting has not yet been enabled, you may [open a general Issue](https://github.com/Fablitox/SoundBoardMaker/issues/new/choose) **without sharing exploitable details**, solely to ask how to communicate the report confidentially.

Never disclose passwords, tokens, file paths containing personal information, private audio recordings or other users' data in public.

### Scope and handling

This public repository contains only the official presentation, documentation and distributions. **The application source code remains private** and is not published here.

Security reports are reviewed on a case-by-case basis. Ordinary software bugs without a security impact should be reported through the [bug report forms](https://github.com/Fablitox/SoundBoardMaker/issues/new/choose).

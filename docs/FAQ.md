# Questions fréquentes

### Soundboard Maker est-il gratuit ou open source ?

Le dépôt public distribue l'application et sa documentation, mais **n'expose pas le code source**. Les conditions exactes de distribution de la version 1.0 seront indiquées lors de sa publication ; ce dépôt n'accorde pas de licence open source.

### Quand la version 1.0 sera-t-elle disponible ?

La version 1.0 est en préparation. Une date n'est pas annoncée pour l'instant. Les téléchargements officiels apparaîtront sur [Releases](https://github.com/Fablitox/SoundBoardMaker/releases) lorsqu'elle sera publiée.

### Pourquoi ne trouve-t-on pas de fichier ZIP portable ?

Soundboard Maker sera distribué avec **un installateur Windows .exe**. Aucune version portable/ZIP n'est prévue.

### Comment installer le plugin Stream Deck ?

Le plugin est proposé séparément au format **.streamDeckPlugin**, tant qu'il n'est pas publié sur Elgato Marketplace. Il s'ouvre avec le logiciel Stream Deck. Voir [Installation](INSTALLATION.md).

### Wave Link est-il obligatoire pour utiliser Soundboard Maker ?

**Non, pas pour écouter vos sons** au casque ou sur vos enceintes : une sortie audio Windows ordinaire suffit.

**Oui, pour diffuser les sons dans votre entrée microphone virtuelle** (Discord, jeux, chat vocal) avec la configuration prise en charge par Soundboard Maker. Il faut utiliser **Elgato Wave Link** pour recevoir les sons sur un canal de sortie, les router vers **MicrophoneFX** et sélectionner ce périphérique comme micro dans l'application vocale. Soundboard Maker ne crée pas lui-même un microphone virtuel.

Voir [Diffuser des sons dans son microphone](INSTALLATION.md#diffuser-des-sons-dans-son-microphone).

### Peut-on lire et sauvegarder les mêmes formats ?

Pas nécessairement. La bibliothèque et les lecteurs peuvent accepter des formats qui ne sont pas proposés pour l'enregistrement ou la sauvegarde de l'éditeur. Vérifiez les choix affichés dans chaque fonctionnalité.

### Le logiciel télécharge-t-il les mises à jour automatiquement ?

Non. Il vérifie les releases au lancement ou via le bouton manuel et peut signaler une nouvelle version. Vous restez maître du téléchargement et de l'installation.

### Où signaler un bug ?

Utilisez les [issues GitHub](https://github.com/Fablitox/SoundBoardMaker/issues) après avoir consulté [Support](SUPPORT.md). N'incluez pas de sons personnels, captures privées, identifiants ou jetons.

# Assistance / Support

Ce dépôt public sert à suivre les retours sur les versions distribuées. Le code source et les discussions de développement internes ne sont pas publics.

## Signaler un problème

Ouvrez une [issue](https://github.com/Fablitox/SoundBoardMaker/issues) avec, si possible :

- La **version de Soundboard Maker** et, si nécessaire, la version du plugin Stream Deck.
- Votre version de Windows et le type de périphérique audio ou Stream Deck concerné.
- Les étapes courtes qui permettent de reproduire le défaut.
- Le résultat attendu et le résultat réellement observé.
- Une capture d'écran expurgée des informations privées si elle apporte une preuve utile.

Avant d'envoyer, **retirez les noms de fichiers personnels, chemins de compte, extraits audio privés, jetons, mots de passe et identifiants** de toute preuve.

Pour un problème de sécurité potentiellement sensible, ne publiez pas de données exploitables dans une issue publique ; privilégiez un canal de signalement privé disponible sur GitHub.

## Support (English)

Open an [issue](https://github.com/Fablitox/SoundBoardMaker/issues) with the app/plugin version, Windows version, reproduction steps and expected/observed results. Remove personal filenames, private recordings, account paths and credentials from any attachment. Report sensitive security issues privately, not through public issue comments.

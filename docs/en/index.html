QUICK ANSWERS

Frequently asked questions.

A few things to know before installing.

Read the full FAQ ↗
Do I need a Stream Deck? +
No. The built-in Soundboard works directly in the Windows application. The optional plugin lets you trigger sounds from Stream Deck keys.
Is Wave Link required? +
Only to route sounds into a virtual microphone (Discord or in-game voice chat) using the supported setup. Normal speaker or headphone playback does not require Wave Link.
Is Soundboard Maker available in French? +
Yes. Soundboard Maker offers both French and English interfaces. This website also has separate language pages.
How do I install the Stream Deck plugin? +
Download the .streamDeckPlugin file from GitHub Releases and open it with Elgato Stream Deck. Manual installation is required until it appears on the Marketplace.
